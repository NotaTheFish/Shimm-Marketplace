1. Рекомендуемый стек
Backend: Node.js + TypeScript
Telegram: grammy или telegraf
API: NestJS или Fastify
Database: PostgreSQL
ORM: Prisma
Cache / locks / rate limits: Redis
Queue: BullMQ
Mini App: React + Vite + TypeScript
UI: Tailwind + shadcn/ui
Validation: Zod
Testing: Vitest + Playwright
Logging: Pino
Monitoring: Prometheus + Grafana / Sentry
Deploy: Docker + Docker Compose, позже Kubernetes

9. Главные правила порядка в коде
1. Никакой бизнес-логики в handlers.
2. Handler только принимает update и вызывает service.
3. Все права проверяются в guards/services.
4. Все деньги проходят только через ledger.
5. Все критические действия имеют idempotency_key.
6. Все callback-кнопки имеют TTL + nonce + подпись.
7. Все state transitions сделки идут через state machine.
8. Все пользовательские тексты проходят sanitizer.
9. Все admin-действия логируются.
10. Все workers идемпотентны.
